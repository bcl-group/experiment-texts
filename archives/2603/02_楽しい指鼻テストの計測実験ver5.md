# 運動計測実習：基礎編（指鼻テスト）
## 2026年3月5日

### 実習における注意事項
- **データの即時確認**: 計測実験では「データを取っては確認」を繰り返すのが基本です。全データを計測し終えた後に不備に気づき，全てやり直しになることがないよう注意してください。
- **全員のデータ解析**: 原則として班員全員のデータを解析してください。個人差の有無を確認することは重要です。
- **役割分担と時間管理**: 準備や操作は役割分担を行い，時間内に終了するよう常に意識してください。
- **解析プログラムの相互確認**: プログラムは各自で作成した後，出力結果が一致するか互いに確認してください。バグの早期発見が重要です。
- **データ管理**: 取得データは，計測用PCのローカルディスクに放置せず，必ず外部HDD等の専用フォルダに格納してください。
- **ファイル名の命名規則**: ファイル名は「日付_グループ名_被験者番号_実験番号_条件.csv」としてください（例：Aグループ1人目，実験1，条件aの場合 → `260305_A_1_1_a.csv`）。
- **計測部位の統一**: カメラ台数の制約により，利き手に関わらず**右側上肢**で計測を行います。
- **指示係を決める**：指示を出す係を1人決める。指示係は，以下の実験をチェックリストに従って実験者に指示を出す（ただし，1.2と2.2の事前準備は，その日の最初の実験の時のみ行う）。被験者役を交代するたびに，指示係は交代する。

## 1. 実験1：指鼻テストの動作計測

### 1.1 使用機器
- [ ] メトロノーム（パソコンかスマホのアプリを使用），筋電センサ一式，モーションキャプチャ一式
- [ ] 計測用PC（筋電用・モーションキャプチャ用），同期ユニット
- [ ] メジャー，両面テープ，サージカルテープ，指サック，反射マーカ
- [ ] 被験者チェックシート（筋電，反射マーカ）とセッションシート


### 1.2 事前準備
- [ ] **カメラ配置**: モーションキャプチャカメラ3台を椅子の右側面，右前方と右後方（椅子からそれぞれ1.5 m，2.5 m，2.5 m程度）に配置する（高さ1.2 m程度）。
- [ ] **画角設定**: OptiTrackソフトウェアを用いてカメラの画角を設定する。
- [ ] **調整・補正**: 同ソフトを用いてキャリブレーションおよび座標設定を実行する。
- [ ] **筋電計接続**: 筋電計測装置とアプリを接続する（筋電計は4個使用）。
- [ ] **同期設定**: OptiTrackが計測開始の信号を出力し，筋電計が信号を受け取ることで計測を開始するようにトリガー設定を行う。また，OptiTrackと筋電計のサンプリング周波数はそれぞれ，180 Hzと1,926 Hzに設定する。
- [ ] **タスク設定**: 4つの筋の最大随意収縮（MVC）の測定および下記の3条件の実験を実行するため，計7個のタスクをアプリ上で設定する。

### 1.3 実験手順
- [ ] **身体特性の記録**: 身長・体重を測定し（学会発表等では重要となるが今回は省略する），利き手を記録する。
- [ ] **ビデオ記録**: ハンディカメラを設置し，録画を開始する（最大筋収縮の電位測定も映すと良い）。
- [ ] **サンプリングレートの確認**: 筋電位の周波数分布はおおむね5 Hz から500 Hz である。したがって，膜電位のサンプリング周波数は，1000 Hz 以上である必要がある。今回は1,926 Hzで計測を行う。
  - [ ] 被験者チェックシートに記入する
- [ ] **筋電センサ貼付とMVCの則的**: 上腕二頭筋，上腕三頭筋，大胸筋中部，三角筋後部の4箇所に筋電センサを貼付する。センサを1つ貼付する毎に，各筋に対して最大随意収縮（MVC）時の筋電位を測定する。
  - [ ] 被験者チェックシートに記入する
  - [ ] データの吸い出しや解析に困らないようにセッションシートにどのデータが記録されているかを記入し，解析時に注意すべきポイントを書く
- [ ] - [ ] **マーカ貼付**: 肘外顆（肘関節）と肩峰（肩関節）に反射マーカを貼付する。その後，示指（人差し指）に反射シール付きの指サックを***慎重に***装着する。
  - [ ] 被験者チェックシートに記入する
- [ ] **距離の記録**: 示指，肘関節，肩関節の各マーカ間の距離を計測する。距離を計測するときは，マーカの中心間の距離を計測する。距離の有効数字はメジャーのメモリの1/10とする。
  - [ ] 被験者チェックシートに記入する
- [ ] **指鼻テストの実施**: 以下の手順で上肢の運動軌道と筋電位を計測する。
    - [ ] 前方のターゲット（マーカ）の位置を15 cmに設定する
    - [ ] 指示係は被験者に次の指示をする。
      - [ ] 「これから，指鼻テストの実験を始めます」
      - [ ] 「このテストは，背もたれに軽く背をつけて行ってください」
      - [ ] 「示指の腹で鼻に軽く触れ，肘を軽く下げてください」
      - [ ] 「開始の合図の後，示指の腹で前方のターゲットの少し下側に軽く触れ，その後，自分の鼻を触る動作を繰り返してください」
      - [ ] 「この動作をメトロノームに合わせながら，10往復繰り返してください。メトロノームは1秒に一回鳴りますので，1往復で2秒かかります。」
      - [ ] 「手首や指の関節はできる限り動かさないようにしてください。」
      - [ ] 「それでは，開始してください」
      - [ ] 指示係は往復の回数をカウントする
      - [ ] （10往復終了後）「終了してください」
      - [ ] データの吸い出しや解析に困らないようにセッションシートにどのデータが記録されているかを記入し，解析時に注意すべきポイントを書く
    - [ ] 同様のテストをターゲットの位置を30 cmと45 cmの場合でそれぞれ行う。指示係は開始とカウント，終了の合図を出す。
- [ ] 実験終了後は，速やかに反射マーカと指サックを取り外すこと（実験2ではモーションキャプチャは行わない）。また，モーションと筋電位のデータの吸い出しを行う。

### 1.4 レポート/プレゼンテーション
1. 指鼻テスト中，肘関節と肩関節はどのように変化しているか。
2. 関節の変化に対して，各筋活動はどのタイミングで発生しているか（力学の問題として捉えて考えること）。
3. 以下の項目について，それぞれ考察せよ。
   - ターゲットの距離によって，運動軌道や筋活動にどのような変化が生じるか。
   - 距離によらない不変な特徴はあるか。
   - 手先軌道や手先の速さの時間変化にどのような特徴があるか。
   - 肘関節角や肩関節角の時間変化にどのような特徴があるか。
4. その他，自分なりの考察や発見を説明せよ。

プレゼンテーション等の資料を作る時には，作ったグラフをやみくもに並べるのではなく，自分の主張を根拠とともに明確に伝えるには，どのグラフ (何についての関係性) を，どのように(縦軸や横軸のレンジ等) 作れば良いかを良く考えること。

## 2. 実験2：姿勢維持実験

### 2.1 使用機器
- [ ] 筋電計測用PC，筋電センサ一式
- [ ] 被験者チェックシート


### 2.2 事前準備
1. 基本的に実験1の設定を引き継ぐ。
2. 実験2ではモーションキャプチャは行わず，筋電測定のみを行う。
3. 下記の4条件の実験を実行するため，計4個のタスクをアプリ上で設定する。

### 2.3 実験手順
- [ ] **ビデオ記録**: ハンディカメラを設置し，録画を開始する（最大筋収縮の電位測定も映すと良い）。
- [ ] **EMG計測**: 上腕を鉛直下向き，前腕を水平に保持した姿勢で，重り（なし，2 kg，4 kg，6 kgの4条件）を10秒間保持した際の筋電位（EMG）を計測する。
  - [ ] からのバケツを用意する。
  - [ ] 指示係は被験者に次の指示をする。
      - [ ] 「これから，姿勢維持実験を始めます」
      - [ ] 「背筋を軽く伸ばしてください。」
      - [ ] 「肘を下に向け，前腕を地面に対して並行にしてください。」
      - [ ] 「これから，おもりの入ったバケツを持っていただいた状態で，その姿勢を10秒間維持してください。」
      - [ ] 被験者にバケツをもたせ，すぐに開始の合図を出す。
      - [ ] 「それでは，開始してください」
      - [ ] 指示係は秒数をカウントする。
      - [ ] （10秒後）「終了してください」
      - [ ] データの吸い出しや解析に困らないようにセッションシートにどのデータが記録されているかを記入し，解析時に注意すべきポイントを書く
    - [ ] 同様のテストをバケツの中に2 kg，4 kg，6 kgのおもりを入れた場合でそれぞれ行う。指示係は開始とカウント，終了の合図を出す。
- [ ] 実験終了後は，速やかに筋電計を取り外すこと。また，モーションと筋電位のデータの吸い出しを行い，次のグループに交代する。

### 2.4 レポート/プレゼンテーション
負荷と上腕二頭筋，上腕三頭筋の筋電位の大きさとの関係を解析し，その結果及び自分なりの発見をレポート (and/or) プレゼンテーションにまとめなさい。
計測データに対しては，いろいろなデータ処理や可視化の方法があり得る。
データの背後にある法則性についての仮説を考え，それを検証するためにはどのようなデータ処理をしてどのようなグラフを作れば良いかよく考えること。以下は主な考察ポイント。
1. 平均的な筋活動はおもりの重量とともに線形に増加するか，非線形に増加するか
2. 重りを持って姿勢維持を続けた場合，筋活動には時間に伴う変化はあるか
3. 以上については，平均値だけでなく標準偏差についても議論すること
4. (optional) 負荷に伴う周波数分布の変化はあるだろうか
5. その他発見はあるか
